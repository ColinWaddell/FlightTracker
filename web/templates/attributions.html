Flight & weather data sources

The sources below are the services Flight Tracker can be configured to use, enabled and ordered on the Settings page's Provider section. Each is used live in real time; none of their data is redistributed with Flight Tracker.

Source Used for Licence and attribution
FlightRadar24 Live aircraft positions (free feed, or the paid FR24 API) Proprietary service data, used as served. Not an open licence, and not redistributed. The Python client (FlightRadarAPI) is an unofficial, MIT-licensed SDK.
OpenSky Network Live aircraft positions Custom data licence, not an open licence: a limited grant for non-profit research and education; operational or commercial REST API use requires a written agreement. Each user enables this provider with their own account and is subject to OpenSky's terms of use.
tar1090 Positions from your own ADS-B receiver, plus aircraft type descriptions tar1090 itself is licensed GPL v2 or later. Type descriptions come from tar1090-db, the aircraft database shipped with that setup (assembled from public sources by Mictronics). Your receiver's data is your own.
ADS-B.fi Live aircraft positions Personal, non-commercial use only, as stated in their open data terms, which ask that adsb.fi be cited with a link.
ADSB.lol Live aircraft positions ODbL 1.0, per their published statement: attribution and share-alike for any derived database.
airplanes.live Live aircraft positions Free API for personal, non-commercial use per their API documentation; access is restricted to feeding stations. No formal open-data licence is published.
HexDB Route and aircraft lookups Free service, no API key. Data courtesy of PlaneBase/PlanePlotter, Jim Mason, Steve Hibberd, ip2location and Airport-Data, as credited on their site.
adsbdb.com Route and airline lookups Free service, no API key. Aircraft data courtesy of PlaneBase; the flight route data is the work of David Taylor (Edinburgh) and Jim Mason (Glasgow) and may not be copied, published or incorporated into other databases without the explicit permission of David J Taylor, as stated in the service's documentation.
ADSB.im routeset Route lookups The served route data is explicitly licensed ODbL 1.0, built from vradarserver standing-data (CC0), parsed ACARS messages and adsb.lol data - see the adsb.im API statement.
AeroDataBox Route and aircraft lookups Commercial API offered through RapidAPI (paid tiers).
AirLabs Route lookups Commercial API with a free plan.
FlightAware AeroAPI Route lookups Commercial API (subscription).
WeatherAPI.com Weather conditions and forecasts Commercial service with a free plan; data used as served, not redistributed.
CelesTrak Satellite orbital elements (TLEs) Freely available orbital data requests follow the CelesTrak usage policy - Flight Tracker caches element sets between updates rather than polling each pass.
OpenStreetMap Maps shown on the Settings page ODbL 1.0. The map itself carries the "© OpenStreetMap contributors" credit.

Bundled lookup data

Unlike the live sources above, these datasets ship with Flight Tracker as part of the application. Each is generated from the public sources listed here.

What it is Source Licence
Airport names and codes (including the extended ICAO/GPS lookup and the IATA↔ICAO maps) OurAirports Public domain, per the source's own statement.
Airline codes and names (IATA↔ICAO conversions, friendly airline names) Wikipedia, "List of airline codes" CC BY-SA 4.0 (Wikipedia's content licence): attribution to Wikipedia contributors; share-alike applies to the derived code tables.
FlightGazer-airlines-db operators.csv - the FAA JO 7340 chapter 3 telephony table with human-reviewed friendly names ODbL v1.0: attribution required, share-alike for the distributed database.
vradarserver/standing-data CC0 1.0: no conditions.
OpenFlights airlines.dat The repository is licensed AGPL-3.0; this file is used only as a tertiary fill of a few hundred entries. Its scope for this dataset is an open question tracked by the project's own data tooling.
Aircraft body-type designators (the Aircraft Types filter's lookup table) Mirror of ICAO DOC 8643 columns from George88000/aircraft_models, plus fills from OpenAircraftType and the FAA JO 7340.2E decode pages DOC 8643 mirror: MIT. FAA pages: US government publication, public domain. OpenAircraftType declares no licence upstream - included with attribution, pending the project's redistribution decision.
Airline logos (16×16 icons shown on the panel) Derived from FlightAware's airline logo images Not an open dataset: the logos are the airlines' trademarks, served by FlightAware and credited here.

Beyond the sources listed, the bundled tables carry manual curation by the project (exclusions, corrections and fills where no source documents a code). The tables are refreshed from the sources above via the project's own data tooling, which prints each build's provenance.
